Palate — Request Flow

Sequence of calls from user tap to restaurant cards

sequenceDiagram
  autonumber
  actor User
  participant Browser as Browser :3000 (Vite/React)
  participant Proxy as Express Proxy :3001 (server/index.ts)
  participant Nominatim as Nominatim (free, no key)
  participant Whisper as OpenAI Whisper API
  participant Claude as Anthropic Claude API
  participant Places as Google Places API (optional)
  participant EL as ElevenLabs TTS API

  User->>Browser: Tap Start
  Note over Browser: getUserMedia() — mic permission prompt
  Note over Browser: VAD loads Silero ONNX model (on-device, no network)
  Browser->>Nominatim: GET /reverse?lat=…&lon=…
  Nominatim-->>Browser: { city }
  Browser->>Proxy: POST /api/speak · { text: greeting }
  Proxy->>EL: POST /v1/text-to-speech/{voice_id}/stream · 🔑 xi-api-key
  EL-->>Proxy: audio/mpeg
  Proxy-->>Browser: audio/mpeg
  Browser->>User: Greeting plays

  User->>Browser: Speaks naturally
  Note over Browser: VAD detects speech end (Silero, on-device)
  Browser->>Proxy: POST /api/transcribe · multipart audio blob
  Proxy->>Whisper: POST /v1/audio/transcriptions · 🔑 Authorization Bearer
  Whisper-->>Proxy: { text: transcript }
  Proxy-->>Browser: { text: transcript }

  Browser->>Proxy: POST /api/chat · { messages: conversation history }
  Proxy->>Claude: POST /v1/messages · 🔑 x-api-key
  Claude-->>Proxy: { spoken text + restaurants JSON block }
  Proxy-->>Browser: parsed response

  Note over Browser: usePlaces — verify each restaurant in parallel (Promise.allSettled)
  Browser->>Proxy: GET /api/places?query=… (×N, one per restaurant)
  Proxy->>Places: GET /findplacefromtext · 🔑 key (skipped if absent)
  Places-->>Proxy: { place_id, formatted_address }
  Proxy->>Places: GET /place/details?place_id=… · fields: editorial_summary
  Places-->>Proxy: { editorial_summary.overview }
  Proxy-->>Browser: enriched: place_id + address + description (or original if no match)

  Browser->>Proxy: POST /api/speak · { text: reply }
  Proxy->>EL: POST /v1/text-to-speech/{voice_id}/stream · 🔑 xi-api-key
  EL-->>Proxy: audio/mpeg
  Proxy-->>Browser: audio/mpeg
  Browser->>User: Reply plays + restaurant cards shown (links use verified place_id)
  Note over User,Browser: Loop — user speaks again or taps a card
Browser → Proxy: same-origin /api/* only — no keys in client
Nominatim: browser-direct, free public API, no key needed
VAD / ONNX: fully on-device after initial .wasm load
🔑 API keys live only in the Express proxy (.env, never bundled)
transcribe → chat → places (parallel) → speak runs serially per turn
Google Places is optional — skipped gracefully if GOOGLE_PLACES_KEY is absent
